Proyek Tugas:
Dikerjakan berkelompok, buat studi kasus menerapkan CURD dengan tema bebas. Di presentasikan pada minggu terakhir. Ketentuan aplikasi:
1.	Menggunakan basis data.
2.	Ada login / register / dashboard
3.	File Master yaitu file yang jarang berubah seperti: Tabel Dosen, Tabel Mahasiswa. Tabel satuan, tabel Barang, tabel customer, tabel supplier. Dll.
4.	File Transaksi: File yang dinamis, yang berubah isinya sesuai dengan trankasi yang dikenakan, seperti: Menjual produk, membeli produk. Isi KRS, Peminjaman buku, pengembalian buku.
5.	File Report: File laporan, bisa dari file master, file transaksi, atau suatu rekap. Laporan pembelian, laporan penjualan, laporan isi KRS, Laporan Transkrip Nilai, laporan peminjaman buku, laporan pengembalian buku, laporan denda, dll.
6.	Dihosting di tempat hosting free (gratis)
